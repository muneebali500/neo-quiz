        🧠 NeoQuiz - Ultimate Knowledge Challenge

        Test your knowledge across 10 categories with timer pressure, stats tracking, and keyboard mastery!

        📖 What It Does

        NeoQuiz delivers trivia challenges from Open Trivia DB API with 10 curated categories. Choose difficulty, race against the timer, track accuracy stats, review mistakes, and compete with shareable scores. Perfect for learning, warm-ups, or Fiverr portfolio demos.

        🎮 How to Use

        • Pick difficulty: 🌱 Easy / ⚡ Medium / 🔥 Hard
        • Select category from 10 themed options (General, Science, Sports, etc.)
        • Customize timer (0-30s) or quick start (5 easy questions)
        • Answer via mouse or keyboard (1-4 keys)
        • Space/N for next, R to restart, Esc closes settings
        • Review detailed feedback and full answer breakdown
        • Share scores: "I got 8/10 on Hard History!"
        • Toggle themes, stats, shortcuts, reduced motion in gear menu

        ✨ Key Features

        • 10 Categories: General, Books, Film, Music, Science, Tech, Sports, Geography, History, Art
        • 3 Difficulties: Adaptive API questions per level
        • Configurable Timer: 0-30s per question with warning/danger visuals
        • Keyboard Shortcuts: 1-4 answers, Space/N next, R restart, Ctrl+T theme cycle
        • Instant Feedback: Correct/wrong highlighting + explanations
        • Answer Review: Full breakdown with ✓/✗ status
        • Performance Messages: Personalized feedback (90%+ = 🏆 Master!)
        • Persistent Settings: Themes, timer, stats saved across sessions
        • Share Results: Native share or clipboard copy
        • Accessibility: Reduced motion, ARIA notices, focus management

        🚀 Key JavaScript Concepts

        • State Management: Centralized state object for quiz flow
        • Async Fetch: Open Trivia DB API with HTML decoding & error handling
        • setInterval/clearInterval: Precise per-question timers
        • Event Delegation: Keyboard shortcuts, click handlers
        • DOM Manipulation: Dynamic options, progress bars, results
        • localStorage: Settings, categories, difficulty persistence
        • Array Methods: map, forEach, find, shuffle Fisher-Yates
        • Error Resilience: API fallbacks, response_code checks
        • ES6+: const/let, arrow funcs, template literals, destructuring
        • Performance: Cached DOM queries, batched updates

        🎨 Design Features

        • 4 Themes: Default, Dark, High-Contrast, Minimal
        • Emoji icons + Font Awesome for categories/options
        • Smooth transitions: Progress fill, timer colors, option feedback
        • Responsive cards: Difficulty, categories scale perfectly
        • Visual stats badges, active highlights, loading states
        • Accessibility notices (fade out after 3s)
        • Clean results with color-coded review items

        💻 Technologies Used

        HTML5 CSS3 Vanilla JavaScript Open Trivia DB API localStorage Fetch API
